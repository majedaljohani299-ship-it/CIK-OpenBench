# CIK OpenBench — النسخة العامة التجريبية

**المؤسس وصاحب التصور العام: ماجد الجهني.** لا تُنشر بيانات اتصال أو هوية شخصية أخرى.

**الحالة: نموذج أولي مستقل؛ لم تُثبت أي زيادة في أداء النماذج.**

هذه حزمة جديدة مكتوبة خصيصًا للنشر المحتمل، وليست نسخًا أو إعادة تسمية لشيفرة CIK التاريخية أو التنفيذ الخاص غير المنشور.

تتيح الحزمة إنشاء أزواج إجابات A/B مع إخفاء تسمية خط الأساس والتجربة، وفصل مفتاح الكشف عن ملف المُقيِّم، ورفض نتائج التقييم الناقصة أو الاختبارات الصفرية. لا تحتاج إلى اتصال بالإنترنت أو مفتاح API. كل البيانات الموجودة في `examples/` اصطناعية.

## التشغيل

من داخل مجلد المشروع، مع Python 3.10 أو أحدث:

```sh
python tools/run_tests.py
python -m cik_openbench prepare --input examples/synthetic_pairs.json --packet out/blind_packet.json --key out/private_key.json --seed 7
python -m cik_openbench score --packet out/blind_packet.json --key out/private_key.json --judgments examples/synthetic_judgments.json --report out/report.json
```

**تنبيه:** لا تنشر الملفات داخل `out/` لأنها قد تحتوي على مفاتيح كشف التقييم. لا تنقل أصولًا خاصة من المشاريع الخاصة إلى المستودع العام. النتائج الاصطناعية تثبت عمل البنية المحلية فقط، ولا تثبت فاعلية الفرضية في العالم الحقيقي.

راجع README.md للتفاصيل التقنية، وdocs/PUBLISH_CHECKLIST.md لفحص الجاهزية قبل النشر، وLICENSE لشروط MIT التي تتيح للآخرين الاستخدام والتعديل والتوزيع.

## ميزة اختيارية: كشف تحيز ترتيب الإجابات (v0.2.0)

المشكلة: قد يختار المقيّم الإجابة الأولى بسبب موضعها. يمكن إنشاء نسختين متعاكستين من كل زوج إجابات:

```sh
python -m cik_openbench prepare --input examples/synthetic_pairs.json --packet out/cb_packet.json --key out/cb_private_key.json --seed 7 --counterbalance
```

كل زوج أصلي ينتج مقارنتين بترتيبين متعاكسين ومعرفات جديدة غير كاشفة. يجب على المقيّم تعبئة حكم مستقل لكل مقارنة بالصيغة الحالية وربطه ببصمة الملف. إذا اختار نتيجتين مختلفتين للإجابة الأصلية نفسها، يعيد الفاحص `BLOCKED_POSITION_INCONSISTENCY` ولا يعتبر الحكم مستقرًا. هذه ميزة **للتحقق من ثبات المقارنة**، وليست كشفًا تلقائيًا للهلوسة أو إثباتًا لتحسن CIK. لا تنشر مفتاح الكشف الخاص.
