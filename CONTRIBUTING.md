# Contributing

Please open an issue describing a reproducible problem before proposing changes. Keep proposed improvements small and include tests for positive, negative, and empty-input cases. CI must never treat zero executed tests or missing judgments as PASS. Do not submit non-public proprietary implementation, private test data, API keys, identifying user data, or confidential project history. Contributors should state whether examples are synthetic or independently measured.

Suggested future work: a precommitted judge rubric, blinded dual judges, consensus and disagreement reporting, leakage checks, reproducible independent holdout protocol, and transparent confidence intervals. Do not claim efficacy from demonstrations.
